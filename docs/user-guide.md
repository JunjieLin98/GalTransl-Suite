# GalTransl Suite 用户手册(新手向)

> 一个拖入游戏目录即可产出中文汉化补丁的桌面套件:自动识别引擎 → 提取文本 →
> LLM 翻译 → 回封打包。本手册面向第一次使用的用户。

## 0. 你需要准备什么

1. **一份你合法持有的游戏**(当前推荐:Kirikiri 系 / Yu-ris 引擎游戏;Unity 游戏
   支持 TextAsset 场景,标注为实验性)。
2. **任意一个 OpenAI 兼容的 LLM API key**(DeepSeek / OpenAI / 本地 sakura 等均可),
   这是唯一需要花钱/配置的东西。翻译质量与费用都取决于你选的模型。

## 1. 启动与连接

启动桌面程序后,左侧栏进入 **🎮 补丁工作台**。程序会自动拉起本地后端
(127.0.0.1:12333,仅本机可访问);如果看到"后端已在线"或页面正常渲染,
连接就没有问题。

## 2. 配置翻译后端

左侧 **🤖 翻译后端配置** 填入你的 API key / endpoint / 模型名
(DeepSeek 示例:endpoint `https://api.deepseek.com`,model `deepseek-chat`)。
也可以稍后直接编辑工程里的 `work/gt_project/config.yaml`。

## 3. 制作补丁(补丁工作台)

1. **① 选择游戏**:填入游戏根目录(与游戏 exe 同级)→ 点「检测引擎」→
   确认识别出的引擎与能力等级(下方有等级说明)→ 点「创建工程」。
2. **② 执行流水线**:点「▶ 运行全部」。
   - 全自动等级(L1/L2)会一路跑到打包:解包 → 提取 → AI 翻译 → 注入 → 打包。
   - 半自动等级(L3)会停在翻译产出,回封需要按指引人工完成。
   - 日志区实时滚动;任务失败会显示错误码与**可行动的处理建议**。
   - 没配 API key 时会在翻译步停下并提示你配置——这是预期行为。
3. 产物在哪:
   - **Kirikiri/Yu-ris**:工程目录 `dist/` 下的补丁文件(patch*.xp3 / 新的归档),
     连同 `安装说明.txt` 一起按说明放进游戏目录即可。
   - **Unity(experimental)**:补丁直接部署进游戏目录(原文件已自动备份到
     工程 `backup/`),按 `dist/` 的说明操作。
4. **取消 / 重跑 / 还原**:任务可取消;支持「从某一步重跑」(断点续翻,
   已翻译部分不会重复计费);改动过游戏文件后可用「还原游戏文件」从备份恢复。

## 4. 校对与改稿(✏️ 双语对照编辑器)

翻译完成后(或翻译中断点续翻到一半时),进入 **双语对照编辑器**:

1. 选择工程目录 → 左侧列出全部文本文件(带统计:锁定/未译/问题数)。
2. 中间是句对网格:左原文右译文,**修改译文后失焦自动保存并锁定**——
   锁定行不会被后续重翻覆盖(你的定稿就是终稿)。
3. 带黄色 ⚠ 的行是自动找错系统标记的可疑翻译;点 ⚠ 可标记
   确认 / 忽略。
4. 改完后点「重建输出」,译文立即写回游戏文件/补丁(不消耗 API 费用)。

## 5. 术语统一(工作台 ③ 术语向导)

「提取术语草稿」会用分词 + LLM 抽出高频专名(人名/地名),生成可编辑草稿;
删改后点「确认 N 条生效」,之后的翻译会把这些作为人设约束,角色名不再漂移。

## 6. 多任务排队

任务运行中再点其它工程的「运行全部」会自动排队,前一个完成后自动开始;
每个任务完成/失败会弹系统通知。

## 7. 常见问题

- **杀毒软件报警**:Kirikiri 补丁可能附带 version.dll(免封包加载组件,MIT,
  见补丁内 LICENSE-THIRD-PARTY.txt),属误报常见对象,加白名单即可。
- **加密封包解不开**:部分游戏需要 xp3brute 等社区解密工具(**自备**,
  本软件不内置)。把 `xp3brute.exe` 放入任一工具目录后重跑 UNPACK 即可,
  流水线会在解包零产物时自动回退调用它;工具目录与检测状态见
  **设置页 → 外部工具**。目录优先级:`--tools-dir` / `GALTRANS_TOOLS_DIR`
  → 用户目录 `%APPDATA%\GalTranslSuite\tools`(推荐,无需管理员权限)
  → 安装目录 tools/bin。
- **从旧版 GalTransl Desktop 升级**:产品改名后安装目录不同,**更新后请
  手动卸载旧版 "GalTransl Desktop"**(设置 → 应用),工程与设置数据不受影响。
- **Unity 游戏提取不到文本**:确认文本在 TextAsset(JSON/TSV 格式);
  文本硬编码在代码里(Il2Cpp)的场景请看 `docs/research/unity-il2cpp.md` 的
  XUAT 引导。
- **能力等级是什么**:L1 全自动 / L2 全自动(受限)/ L3 半自动(仅到翻译)/
  L4 仅翻译。软件按检测到的引擎如实标注,不承诺超出等级的效果。

## 8. 合规提示

请仅对**合法持有**的游戏制作汉化补丁;补丁由 AI 翻译、未经完整人工审校
(补丁内含声明);请勿分发游戏资源本身。
